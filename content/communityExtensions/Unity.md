The [Babylon Unity Toolkit](http://www.babylontoolkit.com) hosts a set of tools designed to provide a small subset of the Unity Editor's design-time features for exporting Babylon.js content scene files. You can create your games using a design-time, component-based architecture. Please refer to the [Unity Editor](https://docs.unity3d.com/Manual/index.html) documentation for details.
