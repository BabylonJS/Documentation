## Adding Files

To add files, simply browse to the desired folder and click the `Import...` button in the Assets Browser toolbar.
A dialog will open to select the files to add. Once selected and confirmed, all selected assets will be copied to
the currently browsed folder.

Whenever a file is added, its thumbnail is generated if its type is recognized and supported.

![AddingFiles](/img/extensions/Editor/AddingFiles/adding-files.webp)

## Supported Mesh Formats
* .babylon
* .fbx
* .gltf
* .glb
* .obj
* .stl

## Supported texture formats
* .png
* .jpg
* .bmp
* .basis
* .dds (cube texture)
* .env (cube texture)

## Supported sound formats
* .mp3
* .ogg
* .wav
