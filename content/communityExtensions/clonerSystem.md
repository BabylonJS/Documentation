This system allows you to take an array of meshes, clone them, and display the results in a variety of patterns.

Be aware that the current documentation refers to the old version of Cloner. Meanwhile, the basic API is the same, so you can use it as a reference.

The new Cloner version is [published on npm](https://www.npmjs.com/package/bp-cloner) and can be installed with <pre>npm i bp-cloner</pre>
