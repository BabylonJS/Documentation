## Event Handling

Naturally, the main sources of events are the mouse, keyboard, touch, device movement, and game controllers. In this section, we will consider how to manage some of these. In terms of coding, Babylon.js has two features that handle events: actions and observables. It is also possible to use plain JavaScript.
